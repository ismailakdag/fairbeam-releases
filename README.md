# Fairbeam releases

Downloads for [Fairbeam](https://github.com/ismailakdag/fairbeam), the open electromagnetic workbench: the desktop app for macOS and Windows, and the runtime components it installs.

- **Download:** the latest version is on the [releases page](https://github.com/ismailakdag/fairbeam-releases/releases/latest). Installed apps update themselves.
- **Windows:** the installer is not code-signed, so SmartScreen asks on the first run: More info › Run anyway. The macOS app is signed and notarized.
- **Report a problem or ask for a feature:** [open an issue](https://github.com/ismailakdag/fairbeam-releases/issues/new/choose).
